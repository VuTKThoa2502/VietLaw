# VIETLAW - Vietnamese Legal Assistant (Multi-Agent Architecture)

**Role:** Business Analyst, Tester  
**Timeline:** 01/2026 - 07/2026  
**Team Size:** 06 members  

## 📌 Project Overview
Vietlaw is an AI-powered legal assistant system built on a Multi-Agent Architecture to help users look up legal clauses, consult on legal situations, and draft administrative documents automatically.
